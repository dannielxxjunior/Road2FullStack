# O que são Cores Nomeadas em CSS e Quando Usá-las?

No CSS, as cores desempenham um papel crucial no design de páginas web, melhorando legibilidade, definindo o clima e aprimorando a experiência do usuário. Uma das maneiras mais simples de definir cores em CSS é usando cores nomeadas. Nomes de cores são nomes predefinidos reconhecidos tanto por navegadores quanto por pessoas.

- Um exemplo de valor de uma cor nomeada é: red; como em color: red;

Cores nomeadas em CSS são uma coleção de 140 nomes de cores padrão como red, blue, yellow, aqua, fuchsia, black, white e por ai em diante. Esses nomes são simples de usar e tornam nosso código mais legível, facil de esrever e também sõa auto-explicativos.

Cores nomeadas são extremamente uteis para prototipagem rápida, designs simples e para melhorar a legibilidade do código.

Vejamos um exemplo do uso de cores nomeadas em um seletor h1:

```html
<link rel="stylesheet" href="styles.css"/>
<h1>This is a heading</h1>
```

```css
h1 {
    color: navy;
    background-color: lightgray;
}
```

Neste exemplo, o texto do cabeçalho será estilizado em navy, com um fundo cinza claro. A legibilidade do código melhora já que as cores nomeadas fornecem uma compreensão visual imediata do estilo pretendido.

---

Cores nomeadas em CSS são convenientes mas limitadas, com apenas 140 opções disponiveis. Elas podem não oferecer o tom exato ecessário para designs mais detalhados.

Cores nomeadas em CSS são também uma otima maneira de aplicar cores de forma rápida e descritiva. Embora sejma úteis para designs básicos, prototipagem e melhoria da legibilidade do código, seu alcance limitado as torna menos adequadas para designs mais complexos que exigem controle preciso das cores.

Ao entender os pontos fortes e as limitações das cores nomeadas, pode agora determinar quando é melhor usá-las em vez de modelos de cores mais detalhados como RGB ou HSL, que aprenderá nas proximas aulas.
