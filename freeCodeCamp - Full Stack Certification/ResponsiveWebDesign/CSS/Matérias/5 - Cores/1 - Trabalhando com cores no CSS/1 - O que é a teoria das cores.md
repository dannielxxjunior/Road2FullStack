# O que é a teoria das cores?

A teoria das cores é o estudo de como as cores interagem entre si e como elas afetam a nossa percepção. Abrange o relacionamento das cores, harmonia e impacto psicológico das cores.
Cores Podem ser classificadas como:

- Primarias
- Secundárias
- Terciárias

As cores primárias, amarelo, azul e vermelho, são os tons fundamentais dos quais todos os outros derivam.

Cores secundárias resultam da mistura de quantidades iguais de duas cores primárias. Verde, laranja e roxo são exemplo de cores secundárias.

Cores terciárias resultam da combinação de uma cor primária com uma cor secundária vizinha. Yellow-green, blue-green e blue-violet são exemplos de cores terceárias.

Esta é uma classificação fundamental no mundo da teoria das cores, mas existem outras formas de classificar as cores. Podem ser classficadas como quentes ou frias com base na sua temperatura.

- Cores quentes como vermelhos, laranjas e amarelos, evocam sensações de conforto, calor e aconchego.

- Cores frias, como azuis, verdes e roxos, evocam sensações de calma, serenidade e profissionalismo.

As cores também podem ser representadas por meio de modelos de cor. Eles são essenciais para descrever e reproduzir cores de maneira padrão. Modelos de cores frequentemente usados incluem o modelo RGB, o modelo HSV e o modelo HSL. ELes representam cores baseadas em diferentes propriedades.

## A Roda das Cores

A roda das cores é um diagrama circular que mostra como as cores se relacionam entre si. É uma ferramenta essencial para designers porque os ajuda a selecionar combinações de cores. Útil para criar paletas e esquemas de cores.

Um esquema de cores é um conjunto de cores escolhido para un design ou projeto específico. Eles geralmente são baseados nos principios da teoria das cores. Ao entendermos as relações entre cores no circulo, podemos desenvolver diferentes tipos de esquemas de cores. Vejamos alguns deles.

Esquemas de cores análogos criam experiencias coesas e relaxantes. Eles têm cores análogas, que são adjacentes uma à outra no círculo cromático.

Esquemas de cores complementares criam alto contraste e impacto visual. As cores desses esquemas estão localizadas nas extremidades opostas da roda de cores, em relação uma à outra.

O contraste é essencial para a acessibilidade na web. Ele garante que o texto e outros elementos importantes sejam claramente distinguiveis do seu fundo. Isso é especialmente importante para pessoas com defeciencias visuais.

Em uma roda de cores RGB, as cores complamentares estão localizadas nas extremidades opostaas da roda. Magenta é complementar ao verde assim como o azul o é para o amarelo.

Um esquema de cores triádico tem cores vibrantes. Eles são feitos de cores que estão aproximadamente equidistantes umas das outras. Se estes esquemas estiverem conectados, formam um triângulo equilátero na roda das cores.

E finalmente temos o esquema de cores monocromático. Neste esquema de cores, todas as cores são derivadas da mesma cor base ajustando sua claridade, escuridão e saturação. Isso evoca uma sensação de unidade e harmonia enqunato ainda cria contraste.

Aqui estão algumas dicas para usarmos a cor de forma eficaz no Web Development:

- Crie um esquema/paleta de cores que defina a identidade visual do seu website.
- Use cores para evocar as emoções e percepções que estejam alinhadas com seus objectivos.
- Escolha cores com contraste suficiente para tornar seu website acessível para todos.
- Use cor para destacar elementos imporantes do seu website, como botões.
- Use a cor de forma consistente e use-a para criar uma hierarquia visual.

A Teoria das Cores é um aspeto fundamental do Design. Ao entender a psicologia das cores, harmonias e acessibilidade, podemos criaaar designs eficazes, evocar emoções e melhorar a experiencia do usuário.
