			Pseudo-classes Estruturais em Árvore
			
			
Pseudo-classes estruturais em árvore permitem que você selecione e estilize elementos com base em sua posição dentro da árvore do documento. A árvore do documento refere-se à estrutura hierárquica dos elementos em um documento HTML.

Aqui está uma lista de pseudo-classes estruturais em árvore:

	•:root
	•:empty
	•:nth-child(n)
	•:nth-last-child(n)
	•:first-child
	•:last-child
	•:only-child
	•:nth-of-type
	•:first-of-type
	•:last-of-type
	•:only-of-type
	
Vamos dar uma olhada mais detalhada em cada uma das pseudo-classes estruturais de árvore, acompanhadas por exemplos.

A pseudo-classe :root é geralmente o elemento raiz HTML. Ele ajudanos a direcionar o nível mais alto do documento para que possamos aplicar um estilo comum a todo o documento.
Vejamos:

HTML:
	<link rel="stylesheet" href="styles.css" />
	<h1>Welcome to My Website</h1>
	<p>This is a sample paragraph to demonstrate the :root pseudo-class.</p>

CSS:
	:root {
	  background: black;
	  color: aliceblue;
	}

Usamos a pseudo-classe :root para definirmos variáveis em CSS também, como no exemplo a baixo:

:root {
	--main-font: 'Arial, sans-serfi';
	--primary-color: blue;
	--secondary-color: green;
}

Com as variáveis em CSS podemos armazenar valores e reutilizá-los na folha de estilos. Aprenderemos mais soubre os mesmo mais adiante.

Elementos vazios,mou seja, elementos sem filhos além de espaços em branco, também estão incluídos na árvore do documento. É por isso que existe a pseudo-classe :empty para direcionar elementos vazios.
 Por exemplo o seguinte código HTML têm dois <li> vazios. Com a pseudo-classe :empty, podemos estilizar os itens de lista vazios de forma diferente.
Vejamos:

HTML:
	<link rel="stylesheet" href="styles.css" />
	<ul>
		<li>Item 1</li>
		<li></li> <!-- Este item está vazio -->
		<li>Item 2</li>
		<li></li> <!-- Este também está vazio -->
		<li>Item 3</li>
	</ul>

CSS:
	:empty {
		background: black;
	}
	
Neste exemplo definimos um background em preto para os itens de lista vazios, mas a coisa mais prática a fazer com os mesmos será usar a propriedade de display: none; para que os itens em vazio não sejam exibidos.
Vejamos:

HTML:
	<ul>
		<li>Item 1</li>
		<li></li> <!-- Este item está vazio -->
		<li>Item 2</li>
		<li></li> <!-- Este também está vazio -->
		<li>Item 3</li>
	</ul>

CSS:
	:empty {
		dipslay: none;
	}
	

 :nth-child(n) permite que possamos selecionar elementos com base na sua posição dentro de um pai, enquanto que :nth-last-child(n) permite que possamos selecionar elementos a partir do final.
 O (n) pode ser número específico ou um palavra-chave como odd ou even (par ou ímpar). Isto é incrivelmente útil para estilizar elementos de tabelas com base na posição: even e odd.
 
 Iremos agora ver um exemplo em HTML de uma tabela de lista de preços de frutas. O CSS está usando a pseudo-classe :nth-child para direcionar as células da tabela com base nas posições ímpares e pares:
 
HTML:
	<link rel="stylesheet" href="styles.css" />
	<table>
		<tr>
			<th>Item</th>
			<th>Preço</th>
		</tr>
		<tr>
			<td>Apple</td>
			<td>$1.05</td>
		</tr>
		<tr>
			<td>Banana</td>
			<td>$0.55</td>
		</tr>
		<tr>
			<td>Orange</td>
			<td>$0.80</td>
		</tr>
	</table>
	
CSS:
	th, td {
		border: 1px solid lightgray;
		padding: 8px;
	}
	
	tr:nth-child(even) {
		background-color: orangered;
	}
	
	tr:nth-child(odd) {
		bakcground-color: lightgreen;
	}


As pseudo-classes :firs-child, :last-child e :only-child atuma em itens dentro de um contêiner pai ou no documento inteiro.

	• :firs-child seleciona o primeiro elemento em u elemento pai ou no documento.
	• :last-child seleciona o último elemento em um elemento pau ou no documento.
	• :only-child seleciona o único elemento em um elemento pai ou no documento.
	
Usar as pseudo-classes :first-child e :last-child selecionará tanto Item 1 e Item 3 no seguinte exemplo:

HTML:
	<link rel="stylesheet" href="styles.css" />
	<ul>
		<li>Item 1</li>
		<li>Item 2</li>
		<li>Item 3</li>
	</ul>
	
CSS:
	li:first-child {
		background-color: orangered;
	}
	
	li:last-child {
		background-color: lightgreen;
	}

	
Se tivermos mais listas não ordenadas na página, precisamos ser mais especificos com a seleção.

Para mostrar como a pseudo-classe :only-child funciona, aqui está um exemplo em HTML com dois elementos <div> separados. Usar a pseudo-classe :only-child garante que apenas o elemnto <div> com um único filho seja selecionado.
Vejamos:

HTML:
	<link rel="stylesheet" href="styles.css />
	<div class="container>
		<div>Este é o único Item neste container.</div>
	</div>
	
	<div class="container">
		<div>Este é um de dois Itens deste segundo container.</div>
		<div>Este é o segundo Item.</div>
		
CSS:
	.container div:only-child {
		border: 2px solid crimson;
		padding: 12px;
		bakground-color: lightblue;
	}
	
	
As pseudo-classes :first-of-type e last-of-type selecionam a primeira e a última ocorrência de um tipo específico de elemento dentro do seu elemento pai. Eles são úteis para aplicar estilos únicos à primeira ou última instância desse tipo de elemento entre seus irmãos.

No exemplo a baixo, :first-of-type e :last-of-type se aplicam ao primeiro elemento e ao último elemento dentro do elemento section.
Vejamos:

HTML:
	<link rel="stylesheet" href="styles.css" />
	
	<section>
		<h2>Introdução</h2>
		<p>Este é o primeiro parágrafo da primeira seção</p>
		<p>Segundo parágrafo da primeira seção</p>
	</section>
	
	<section>
		<h2>Detalhes</h2>
		<p>Este é o primeiro parágrafo da segunda seção</p>
		<p>Este é o segundo parágrafo da segunda seção</p>
	</section>
	
CSS:
	section p:first-of-type {
		background-color: lightgreen;
	}
	
	section p:last-of-type {
		background-color: lightblue;
	}
	
	
:nth-of-type(n) permite-nos selecionar um elemento específico dentro de seu pai com base em sua posição entre irmãos do mesmo tipo. Por exemplo, no HTML abaixo, nth-of-type(2) seleciona o segundo elemento no contêiner.
Vejamos:

HTML:
	<link rel="stylesheet" href="styles.css" />
	
	<div class="container">
		<p>Primeiro parágrafo</p>
		<p>Segundo parágrafo</p>
		<p>Terceiro parágrafo</p>
	</div>
	
CSS:
	p:nth-of-type(2) {
		color: red;
		sont-weight: bold;
	}
	
	
:only-of-type seleciona um elemento se ele for o único do seu tipo dentro do seu pai. Isso pode ser útil para enfatizar itens únicos ou garantir que eles sejam estilizados de forma diferente quando não fazem parte de um grupo.

No exemplo que veremos abaixo há dois elementos <div> sendo que um deles possui um único elemento. O CSS se aplica apenas ao primeiro contêiner.
Vejamos:

HTML:
	<link rel="stylesheet" href="styles.css" />
	
	<div class="container">
		<p>O único parágrafo</p>
	</div>
	
	<div class="container">
		<p>Primeiro parágrafo</p>
		<p>Segundo parágrafp</p>
	</div>
	
CSS:
	p:only-of-type {
		border: 4px solid green
	}
